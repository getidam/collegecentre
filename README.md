## 🏛️ Overview

**CollegeCentre** replaces obsolete, fragmented campus ERPs and bureaucratic paper chaos with a unified, tamper-proof **Student Lifecycle & Campus Operating System**. Built with high-impact, editorial brutalist aesthetics inspired by public-movement digital design principles.

### Key Architectural Directives:
1. **Zero Transcript Forgery:** Cryptographically signed (SHA-256) academic marksheets & provisional degrees verifiable in under 2 seconds.
2. **1-Click Universal Semester Enrollment:** Automated prerequisite evaluation, quota management, and instant timetable generation.
3. **100% Reconciled Fee Escrow & Scholarships:** Direct payment gateway integration with automated subsidy adjustments and zero-leakage accounting.
4. **Role-Based Data Privacy (DPDPA 2023 & FERPA):** Granular departmental permissions with tamper-evident audit logs.
5. **1-Click Institutional Accreditation Audit:** Automated quantitative data generation for NAAC, NIRF, and NBA compliance reports.

---

## ⚡ Interactive Features

- **Interactive Digital Student Pass Generator:** Real-time photorealistic student & registrar ID badge creator with custom avatars, dynamic QR verification codes, department tags, and 1-click high-resolution PNG export with celebration effects.
- **Modular Campus OS Explorer:** Deep-dive interactive simulations of the SIS Core, Examination Engine, Geo-fenced Attendance, Fee Escrow, and Campus Placements.
- **Live Institutional Telemetry:** Real-time campus activity feeds and metrics.
- **Executive Onboarding & Sandbox Booking:** Integrated request dispatch modal for university registrars and IT leadership.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS 3.4 (Custom editorial paper palettes, brutalist borders, and Oswald display typography)
- **Icons:** Lucide React
- **Credential Rendering:** `qrcode.react` + `html-to-image` + `canvas-confetti`

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/getidam/collegecentre.git
cd collegecentre.in
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
